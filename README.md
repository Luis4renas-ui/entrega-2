# 🫓 ArepaVibe - Página Web Profesional de Arepas

Una página web moderna, responsiva y profesional para una empresa de arepas artesanales. Diseñada con React, Vite y Tailwind CSS.

## ✨ Características

- **Diseño Responsivo**: Adaptable a dispositivos móviles, tablets y desktops
- **Paleta de Colores Premium**: Tonos dorados, amarillos y cálidos que evocan el maíz
- **Componentes Reutilizables**: Arquitectura limpia y organizada
- **Animaciones Suaves**: Transiciones y efectos hover atractivos
- **Formulario de Contacto**: Con validación básica y mensaje de éxito
- **SEO Friendly**: Estructura HTML semántica
- **Rendimiento Optimizado**: Vite para construir rápido

## 🎨 Secciones

1. **Navbar**: Navegación sticky con menú responsivo
2. **Hero**: Sección de bienvenida con call-to-action
3. **Menú de Productos**: 6 arepas con descripción, imagen (emoji) y precio
4. **Sobre Nosotros**: Historia de la empresa y estadísticas
5. **Contacto**: Formulario y información de comunicación
6. **Footer**: Enlaces rápidos, horarios y suscripción

## 🚀 Instalación y Uso

### Requisitos
- Node.js (v14 o superior)
- npm o yarn

### Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Vista previa del build
npm run preview
```
